# taiwan-breakfast-healthy-food-tracking-analysis-
怎麼用  輸入性別、身高、體重、腰圍和體脂率，按「分析」。 畫面會顯示 BMI 色階條（標出你的位置）、腰圍與體脂率是否超標，以及你的警示等級。 下方會列出「你應該避開的食物」。 在最下面點選食物組成一餐，會算出整餐的風險並給替換建議，不是只看單一品項。  警示等級的算法 BMI、腰圍、體脂率各自超標會加分，分數越高，避開名單越長。  標準：只避開 ☠️ 極高風險食物，例如炸雞堡、奶酥厚片、黑糖珍奶。 加強：避開 🔴 以上，🟠 偶爾吃。 嚴格：連 🟠 以上都避開，例如蔥抓餅、鮪魚美乃滋起司堡、煎餃。
