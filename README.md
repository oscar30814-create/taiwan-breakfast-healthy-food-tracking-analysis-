# taiwan-breakfast-healthy-food-tracking-analysis-
怎麼用  輸入性別、身高、體重、腰圍和體脂率，按「分析」。 畫面會顯示 BMI 色階條（標出你的位置）、腰圍與體脂率是否超標，以及你的警示等級。 下方會列出「你應該避開的食物」。 在最下面點選食物組成一餐，會算出整餐的風險並給替換建議，不是只看單一品項。  警示等級的算法 BMI、腰圍、體脂率各自超標會加分，分數越高，避開名單越長。  標準：只避開 ☠️ 極高風險食物，例如炸雞堡、奶酥厚片、黑糖珍奶。 加強：避開 🔴 以上，🟠 偶爾吃。 嚴格：連 🟠 以上都避開，例如蔥抓餅、鮪魚美乃滋起司堡、煎餃。 

食物資料庫
共 76 項，分成堡、厚片、蛋餅麵、點心、包捲、飲品六類。風險分 1 到 5，沿用你整理的排名：

1～2 分（綠、黃）：無糖豆漿、無糖美式、白饅頭、原味蛋餅。
3 分（橘）：蔥抓餅、煎餃、鮪魚美乃滋起司堡。
4 分（紅）：鐵板麵、總匯三明治、奶茶。
5 分（深紫）：炸雞腿蛋堡、奶酥／花生／巧克力厚片、黑糖珍奶。

需要注意

風險分數是依你的清單做的排名，不是實際營養成分。如果之後要做精準的每日熱量，需要補上每項食物的熱量、蛋白質、糖和鈉數值。
「每日飲食總評」（0 到 100 分）這版還沒做，目前只評一餐。
頁面頂端有免責聲明，說明這只是參考，不是醫療建議。

"每日總評"怎麼用?

1.選食物，下方八個欄位會帶入每 100g 的數值：熱量（Kcal）、蛋白質、脂肪、飽和脂肪、反式脂肪、碳水化合物、糖（以上為 g）、鈉（mg）。
2.填入你實際吃的克數，按「加入今日紀錄」。
3.加進去的每一筆會累計，並算出 0 到 100 分的今日飲食健康分數。
4.每項營養素都有進度條，綠色是範圍內、黃色是接近上限、紅色是超標，下方還有文字分析。

分數與基準

熱量目標預設 1800 Kcal，可以自己改。
基準是我依國人膳食營養素參考攝取量概估的：蛋白質約 15% 熱量、脂肪 ≤30%、碳水 ≤60%、飽和脂肪和糖各 ≤10%、反式脂肪 ≤1%、鈉 ≤2400 mg。
蛋白質不足會扣分，其他項目超標會扣分。

需要你注意

營養數值是我的估計：只有 25 項常見食物帶入了預設值，其餘 50 多項要自己填。這些數值請以包裝上的營養標示為準。
公開前要核對數值：如果要公開給一般使用者，建議把每個食物的數值對照食品營養成分資料庫確認過。
紀錄不會保存：今日紀錄只存在目前這個頁面，重新整理就會清空。
